# odin-recipes

Project ini adalah latihan membuat halaman web sederhana menggunakan HTML dan CSS, sebagai bagian dari kurikulum The Odin Project.

## Tujuan Project
Melalui project ini, saya akan mempraktifkkan:
-Struktur dasar HTML (heading, paragraf, list, gambar, link) 
-Navigasi antar halaman menggunakan tag <a>
-Dasar-dasar git dan GitHub untuk version control

##Refleksi 
Project ini membantu saya memahami cara kerja git secara nyata, mulai dari clone repository, membuat perubahan, hingga commit dan push ke GitHub.
